5. Did you add a bonus feature to your submission? If so, what is it and how should we see it?

We added improvements to the search component:
- Pressing Enter in the search box runs the search.
- Changing the category dropdown re-runs the search automatically (when there is already a search term).
- Switching the category no longer breaks the page, because the results display now follows the category the results came from.

To see them, open the home page, type a search term, and press Enter. Then switch the dropdown between artist, album, and track.
